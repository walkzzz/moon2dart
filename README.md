## 📖 简介 | Introduction

**moon2dart** 是一个 MoonBit → Dart/Flutter 代码生成器（transpiler），支持**双向转换**与**语义等价性验证**。

它将 MoonBit 源码解析为 AST，再转换为 Dart 代码字符串——同时支持 Dart → MoonBit 反向转换，并通过 **四级语义分类**（L1-L4）确保往返正确性。v0.10.0 引入 strict 模式与诊断标注；v0.11.0 建立运行时语义保持体系（Int 32 位回绕模拟 + 双语义模式 + golden 双端逐行验证），语义等价从"类型可还原"升级到"运行时逐行一致"。

- **库 API**：供其他开发者引入，调用 `transpile_source` / `reverse_transpile_source` / `transpile_source_strict` 等函数
- **CLI**：`moon2dart convert <file>` 命令行转换，支持 `--strict` / `--reverse` / `--pure-only`
- **MCP 服务器**：AI 工具链集成，6 工具注册 + Agent 模式
- **独立**：MoonBit 代码本身独立可运行，不依赖生成的 Dart/Flutter 代码
- **多后端**：支持 wasm / wasm-gc / js / native 四后端
- **语义验证**：L1 等价 / L2 安全转换 / L3 受限 / L4 不等价 + strict 拒绝
- **运行时语义保持**：Int 32 位回绕模拟层（mb32*）+ `--semantics` 双模式（Wrapping/Fast）+ golden 双端验证 14/14 行一致（复现：`node scripts/golden_check.mjs`）

## 🚀 快速开始 | Quick Start

### 库 API — 从源码转换

```moonbit
fn main {
  let src = "fn add(a : Int, b : Int) -> Int { a + b }"
  let dart_code = @moon2dart.transpile_source(src)
  println(dart_code)
}
```

输出：

```dart
// Generated by moon2dart v0.11.0
// DO NOT EDIT BY HAND

int add(int a, int b) {
  return a + b;
}
```

### 库 API — strict 模式（拒绝 L4 映射）

```moonbit
fn main {
  let src = "fn foo(x : Unit) -> Unit { ignore(x) }"
  match @moon2dart.transpile_source_strict(src) {
    Ok(dart_code) => println(dart_code)
    Err(e) => println("L4 rejected: \{e}")
  }
}
```

### 库 API — 反向转换（Dart → MoonBit）

```moonbit
fn main {
  let dart_src = "int add(int a, int b) { return a + b; }"
  let moon_code = @moon2dart.reverse_transpile_source(dart_src)
  println(moon_code)
}
```

### CLI — 命令行转换

```bash
moon run cmd/main --target native -- convert example.mbt
```

## 📚 API 概览 | API Reference

### 正向转换（MoonBit → Dart）

| 函数 | 签名 | 说明 |
|------|------|------|
| `transpile_source` | `String -> String` | MoonBit 源码 → Dart 代码（完整管线） |
| `transpile_source_strict` | `String -> String raise Moon2DartError` | strict 模式（拒绝 L4 映射，含诊断标注） |
| `transpile_source_pure` | `String -> String` | 源码 → Dart（跳过 FFI 声明） |
| `transpile_source_with_lib` | `(String, String) -> String` | 源码 → Dart（指定 FFI 库名） |
| `transpile_source_flutter` | `String -> String` | 源码 → Flutter 应用代码（含 widget/import/runApp） |
| `transpile` | `Array[@ast.MoonDecl] -> String` | 转换声明数组为 Dart 代码 |
| `transpile_with_lib` | `(Array[@ast.MoonDecl], String) -> String` | 转换声明数组（指定 FFI 库名） |
| `transpile_flutter` | `Array[@ast.MoonDecl] -> String` | 转换声明数组为 Flutter 应用代码 |
| `transpile_decl` | `@ast.MoonDecl -> String` | 转换单个声明 |
| `transpile_expr` | `@ast.MoonExpr -> String` | 转换表达式 |
| `transpile_type` | `@ast.MoonType -> String` | MoonBit 类型 → Dart 类型字符串 |

### 反向转换（Dart → MoonBit）

| 函数 | 签名 | 说明 |
|------|------|------|
| `reverse_transpile_source` | `String -> String` | Dart 源码 → MoonBit 源码 |
| `reverse_transpile` | `Array[@dart_ast.DartDecl] -> String` | Dart AST → MoonBit 源码 |

### 项目级操作

| 函数 | 签名 | 说明 |
|------|------|------|
| `transpile_project` | `String -> String` *(async)* | 项目级转换（扫描 + 拓扑排序 + 批量转换） |
| `sync_project` | `(String, String, IncrementalCache) -> SyncResult` *(async)* | 增量同步（hash 对比 + 变更检测） |

## 💻 CLI 用法 | CLI Usage

```bash
# 基础转换
moon run cmd/main --target native -- convert <file.mbt>                # 转换 .mbt 文件为 Dart
moon run cmd/main --target native -- convert <file.mbt> --pure-only    # 跳过 FFI 声明
moon run cmd/main --target native -- convert <file.mbt> --lib libfoo.so # 指定库名
moon run cmd/main --target native -- convert <file.mbt> --strict       # strict 模式（拒绝 L4 映射）

moon run cmd/main --target native -- convert <file.dart> --reverse     # Dart → MoonBit 反向转换

# 项目级操作
moon run cmd/main --target native -- project <dir> -o <output>         # 项目级转换
moon run cmd/main --target native -- sync <dir> -o <output>            # 增量同步

# MCP 服务器
moon run cmd/main --target native -- serve [--http 8080]               # MCP 服务器（HTTP 模式）

# 其他
moon run cmd/main --target native -- demo                              # 演示模式
moon run cmd/main --target native -- help                              # 显示帮助
```

## ✅ 语义等价 | Semantic Equivalence

v0.10.0 引入完整的语义等价性验证体系，让 MoonBit → Dart 的类型映射安全性**可审计、可验证、可拒绝**；v0.11.0 叠加运行时语义保持——Int 算术经 mb32* 回绕模拟层在 Dart 侧复现 MoonBit 32 位语义。

### 四级分类

| 等级 | 含义 | 示例 |
|------|------|------|
| **L1-EQUIVALENT** | 语义完全等价 | `Int → int`，`String → String` |
| **L2-SAFE** | 安全转换（无损） | `Double → double`，`Bool → bool` |
| **L3-CONSTRAINED** | 受限转换（语义收缩） | 嵌套 `Option<Option<T>>` → `T?`（null 嵌套丢失） |
| **L4-INEQUIVALENT** | 不等价（语义漂移） | `Unit → void`（值 vs 无返回） |

### 关键机制

- **Nested Option 辅助类** — `is_nested_option` 检测 + `emit_option_class` 生成 Dart 辅助类
- **DResult 结构化节点** — `DResult(DartType, DartType)` 替代 DCustom 退化，精确映射 `Result[T, E]`
- **诊断标注** — `emit_semantic_diagnostic` 在生成代码中插入 `[L3-CONSTRAINED]` / `[L4-INEQUIVALENT]` 注释
- **strict 模式** — `--strict` 拒绝所有 L4 映射，返回 `Moon2DartError`
- **变异测试** — `assert_round_trip` + `assert_value_domain` 验证往返语义保持
- **运行时语义保持** — `SemanticsMode` 双模式（Wrapping 默认 / Fast）+ mb32* 回绕 shim + mini 类型推断器；golden 双端 14/14 行一致

详见 [docs/semantic_equivalence.md](docs/semantic_equivalence.md)。
