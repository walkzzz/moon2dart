# moon2dart
> MoonBit → Dart transpiler | 让 MoonBit 代码跑在 Flutter 上

[![CI](https://github.com/walkzzz/moon2dart/actions/workflows/ci.yml/badge.svg)](https://github.com/walkzzz/moon2dart/actions/workflows/ci.yml)

## 简介

**moon2dart** 是一个 MoonBit → Dart/Flutter 代码生成器（transpiler）。它将 MoonBit 源码解析为 AST，再转换为 Dart 代码字符串。

- **库**：供其他开发者引入使用，调用 `transpile_source` 等 API 从源码生成 Dart 代码
- **CLI**：`moon2dart convert <file.mbt>` 命令行转换
- **独立**：MoonBit 代码本身独立可运行，不依赖生成的 Dart/Flutter 代码
- **多后端**：支持 wasm / wasm-gc / js / native 四后端

## 安装

```bash
moon add walkzzz/moon2dart
```

## 快速开始

### 库 API — 从源码转换

```moonbit
fn main {
  let src = "fn add(a : Int, b : Int) -> Int { a + b }"
  let dart_code = @moon2dart.transpile_source(src)
  println(dart_code)
}
```

输出：

```dart
// Generated by moon2dart v0.6.0
// DO NOT EDIT BY HAND

int add(int a, int b) {
  return a + b;
}
```

### CLI — 命令行转换

```bash
moon run cmd/main --target native -- convert example.mbt
```

## API 概览

| 函数 | 签名 | 说明 |
|------|------|------|
| `transpile_source` | `String -> String` | MoonBit 源码 → Dart 代码（完整管线） |
| `transpile_source_pure` | `String -> String` | 源码 → Dart（跳过 FFI 声明） |
| `transpile_source_with_lib` | `(String, String) -> String` | 源码 → Dart（指定 FFI 库名） |
| `transpile` | `Array[@ast.MoonDecl] -> String` | 转换声明数组为 Dart 代码 |
| `transpile_with_lib` | `(Array[@ast.MoonDecl], String) -> String` | 转换声明数组（指定 FFI 库名） |
| `transpile_decl` | `@ast.MoonDecl -> String` | 转换单个声明 |
| `transpile_expr` | `@ast.MoonExpr -> String` | 转换表达式 |
| `transpile_type` | `@ast.MoonType -> String` | MoonBit 类型 → Dart 类型字符串 |

## 包结构

```
moon2dart/
├── ast/           # MoonBit AST 节点定义（MoonType/MoonExpr/MoonPattern/MoonDecl）
├── typesys/       # MoonBit → Dart 类型映射（DartType + map_type + emit_dart）
├── codegen/       # Dart 代码发射器（emit_dart_expr/pattern/decl/program）
├── parser/        # 词法分析器 + 语法分析器（Lexer + Parser）
├── cmd/main/      # CLI 入口（convert/demo/help 子命令）
└── docs/          # 设计文档（7 份）
```

## CLI 用法

```bash
moon run cmd/main --target native -- convert <file.mbt>                # 转换 .mbt 文件为 Dart
moon run cmd/main --target native -- convert <file.mbt> --pure-only    # 跳过 FFI 声明
moon run cmd/main --target native -- convert <file.mbt> --lib libfoo.so # 指定库名
moon run cmd/main --target native -- demo                              # 演示模式
moon run cmd/main --target native -- help                              # 显示帮助
```

## 路线图

最终目标：引入 moon2dart 后自动将整个 MoonBit 项目转换为同步的 Flutter/Dart 项目。

四条交付线：库 API（`moon add`）/ CLI（`mooncakes.io/cli`）/ Skill（`mooncakes.io/skills`）/ MCP 服务器。

| 版本 | 状态 | 内容 |
|------|------|------|
| v0.1.0 | ✅ 已实现 | transpiler 骨架（AST + 类型映射 + codegen） |
| v0.2.0 | ✅ 已实现 | 解析器（MoonBit 源码 → AST） |
| v0.3.0 | ✅ 已实现 | trait + 模式匹配 + derive 生成 |
| v0.4.0 | ✅ 已实现 | 项目级扫描 + 包结构映射 |
| v0.5.0 | ✅ 已实现 | async + Option + Result + 泛型 + 闭包 |
| v0.6.0 | ✅ 已实现 | FFI 混合模式（extern c to dart:ffi + String bridge + --pure-only） |
| v0.7.0 | 📋 计划 | Flutter widget 转换 |
| v0.8.0 | 📋 计划 | 自动触发 + 项目同步（核心功能） |

| v1.0.0 | 📋 计划 | 验证 + 完整发布（mooncakes.io） |
