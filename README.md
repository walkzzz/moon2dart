# moon2dart
> MoonBit → Dart transpiler | 让 MoonBit 代码跑在 Flutter 上

[![CI](https://github.com/walkzzz/moon2dart/actions/workflows/ci.yml/badge.svg)](https://github.com/walkzzz/moon2dart/actions/workflows/ci.yml)

## 简介

**moon2dart** 是一个 MoonBit → Dart/Flutter 代码生成器（transpiler）。它将 MoonBit AST 转换为 Dart 代码字符串，让 MoonBit 代码能生成对应的 Dart/Flutter 代码。

- **库**：供其他开发者引入使用，调用 `transpile` 等 API 生成 Dart 代码
- **独立**：MoonBit 代码本身独立可运行，不依赖生成的 Dart/Flutter 代码
- **多后端**：支持 wasm / wasm-gc / js / native 四后端

## 安装

```bash
moon add walkzzz/moon2dart
```

## 快速开始

```moonbit
fn main {
  let prog = [
    @ast.DFn("add", [("a", @ast.MInt), ("b", @ast.MInt)], @ast.MInt,
      @ast.EBinOp("+", @ast.EVar("a"), @ast.EVar("b")))
  ]
  let dart_code = @moon2dart.transpile(prog)
  println(dart_code)
}
```

输出：

```dart
// Generated by moon2dart v0.1.0
// DO NOT EDIT BY HAND

int add(int a, int b) {
  return a + b;
}
```

## API 概览

| 函数 | 签名 | 说明 |
|------|------|------|
| `transpile` | `Array[@ast.MoonDecl] -> String` | 转换声明数组为 Dart 代码 |
| `transpile_decl` | `@ast.MoonDecl -> String` | 转换单个声明 |
| `transpile_expr` | `@ast.MoonExpr -> String` | 转换表达式 |
| `transpile_type` | `@ast.MoonType -> String` | MoonBit 类型 → Dart 类型字符串 |

## 包结构

```
moon2dart/
├── ast/           # MoonBit AST 节点定义（MoonType/MoonExpr/MoonPattern/MoonDecl）
├── typesys/       # MoonBit → Dart 类型映射（DartType + map_type + emit_dart）
├── codegen/       # Dart 代码发射器（emit_dart_expr/pattern/decl/program）
├── cmd/main/      # CLI 演示入口
└── docs/          # 设计文档（7 份）
```

## CLI 用法

```bash
moon run cmd/main    # 演示模式：内置 AST 示例 → Dart 输出
```
