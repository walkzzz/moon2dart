## 3. 核心实现

### 3.1 typesys/mapping.mbt
- `MoonType` 枚举：MInt/MUInt/MInt64/MUInt64/MDouble/MFloat/MBool/MString/MChar/MUnit/MArray/MMap/MSet/MOption/MResult/MCustom
- `DartType` 枚举：DInt/DInt64/DDouble/DBool/DString/DRune/DVoid/DList/DMap/DSet/DNullable/DCustom
- `map_type(MoonType) -> DartType`
- `emit_dart(DartType) -> String`
- `moon_to_dart_type(MoonType) -> String`（便捷）
- `is_pure(MoonType) -> Bool`（判断可纯退化）
- `needs_result_type(MoonType) -> Bool`（是否需自定义 Result）

### 3.2 ast/ast.mbt
- `MoonExpr`：EInt/EDouble/EBool/EString/EVar/ECall/EBinOp/EIf/EMatch
- `MoonDecl`：DFn/DStruct/DEnum
- `MoonPattern`：PVar/PInt/PString/PWild/PCtor

### 3.3 codegen/emitter.mbt
- `emit_dart_type(DartType) -> String`
- `emit_dart_expr(MoonExpr) -> String`
- `emit_dart_decl(MoonDecl) -> String`
- `emit_dart_program(Array[MoonDecl]) -> String`（含文件头）

### 3.4 moon2dart.mbt
- `transpile(Array[MoonDecl]) -> String`：编排入口
- `transpile_file(input : String) -> String`（v0.2.0 parser 就绪后）

### 3.5 cmd/main/main.mbt
- 解析参数：`moon2dart <input> -o <output>`
- v0.1.0 演示模式（无 parser，用内置 AST 示例）
