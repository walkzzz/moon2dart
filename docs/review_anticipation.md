## D. 建议的下一步（按优先级）

1. **差分随机测试**（0.13.0）：随机生成 Array/Int 业务函数输入（空/边界/重复/大数），
   双端比对输出，补齐"样本太小"的质疑（📋 #13）；
2. **数值格式化 golden**：`1.0` / `-0.0` / `NaN` / `Infinity` / 大整数（📋 #5）；
3. **字符串/Unicode golden**：代理对、组合字符、`length` 语义（📋 #6）；
4. **位运算与复合赋值**：要么实现 shim，要么在解析器给出明确"不支持"诊断码（当前是通用 ParseError）；
5. **真实 corpus 接受/拒绝率**：对 20-50 个公开 MoonBit 文件统计（📋 #20）；
6. **fixture 单源生成**：从同一 `.mbt` 生成 MoonBit 真值端与 Dart 转换端，消除 drift（📋 #14）。
