# moon2dart 编码规范

> 已实现 v0.1.0 · 2026-11-06

## 1. MoonBit 源码规范

### 1.1 文件组织
- 每个包一个目录，含 `moon.pkg`
- 源文件用 `.mbt`，测试文件用 `_test.mbt`（blackbox）/ `_wbtest.mbt`（whitebox）
- **注意**：源文件名不能含 `_test`（会被视为测试文件）

### 1.2 代码风格
- 块风格：每个定义以 `///|` 分隔
- `pub fn` 必须有 `///` 文档注释
- 方法定义：`fn Type::meth(self : Type, ..)`
- 布尔取反：`!expr`（非 `not(x)`）
- range：`0..<n`（排他）/ `0..=n`（包含）
- 字符串插值：`\{expr}`

### 1.3 trait 使用
- 跨包实现用 `pub(open) trait`
- impl：`pub impl Trait for Type with method` + `pub extend Type with Trait::{method}`
- derive：`derive(Debug, Eq)` + `pub extend Type with Trait::{method}`

### 1.4 命名
- 类型：PascalCase（`MoonType`、`DartEmitter`）
- 函数/变量：snake_case（`emit_dart`、`map_type`）
- 常量：UPPER_SNAKE（`DEFAULT_INDENT`）
- 包：snake_case（`typesys`、`codegen`）

## 2. 生成 Dart 代码规范

### 2.1 风格
- 遵循 `dart format` 默认风格
- 缩进 2 空格
- 行宽 80 字符
- 生成可读代码（非压缩），便于人工审查

### 2.2 结构
```dart
// 文件头：自动生成标记
// Generated by moon2dart v0.1.0
// Source: input.mbt
// DO NOT EDIT BY HAND

// 1. imports
import 'dart:typed_data';

// 2. 自定义类型（如 Result）
class Result<T> { ... }

// 3. 类型声明（struct → class）
class Point { ... }

// 4. enum → sealed class
sealed class Color { ... }

// 5. 函数
int add(int a, int b) { ... }
```

### 2.3 命名保持
- MoonBit 标识符原样保留（MoonBit 和 Dart 命名规则兼容）
- 关键字冲突时加 `$` 前缀（如 MoonBit `class` → Dart `$class`）

## 3. 测试规范

### 3.1 测试文件
- blackbox：`xxx_test.mbt`（测试公开 API）
- whitebox：`xxx_wbtest.mbt`（测试内部）
- 每个 pub fn 至少一个测试

### 3.2 断言
- 优先 `assert_eq`
- 类型映射测试：`assert_eq(map_type(MInt), DInt)`
- codegen 测试：`assert_eq(emit_dart_type(DInt), "int")`
- 快照测试：复杂输出用 `debug_inspect` + snapshot

## 4. 验收门禁

```bash
moon check          # 0 warning 0 error
moon test           # 全通过
moon fmt            # 格式化
moon info           # API 变更检查
```

每次提交前必须通过四项门禁。

## 5. 提交规范

- 单一 commit per 迭代
- 格式：`vX.Y.Z: <摘要> — <变更点>`
- 示例：`v0.1.0: transpiler 骨架 — 类型映射 + AST + codegen + CLI`
